# Code of Conduct

We want a respectful, harassment-free environment for everyone working on Eagle Eye.

- Be respectful and constructive; critique code and ideas, not people.
- No harassment, discrimination, or personal attacks.
- Respect confidentiality: never share private engineering documents, cabinet photos, or credentials.
- Credit others' work and respect licenses.
- Assume good faith; ask for clarification before judging.

Report concerns to the project maintainers (contact PENDING; see [CONTRIBUTING.md](CONTRIBUTING.md)). Maintainers may remove contributions or contributors that violate these expectations. This text is adapted in spirit from common community codes of conduct and is a lightweight placeholder; adopt a standard text (e.g., Contributor Covenant) if the project grows.
