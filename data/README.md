# data/
Local datasets. Contents of `raw/ interim/ processed/ annotations/` are git-ignored (only `.gitkeep` markers are tracked). `raw` = untouched downloads; `interim` = cleaned/merged work; `processed` = YOLO-ready train/val/test; `annotations` = label exports and guideline versions. Do not commit confidential data. See [DATASET.md](../DATASET.md).
